# MINI-COURIER PLANNER
## Design and Analysis of Algorithms (DAA)

### 1. Introduction
Mini-Courier Planner is a Python-based application designed to optimize parcel selection and delivery route planning.

### 2. Problem Statement
Courier services need to prioritize parcels, manage limited carrying capacity, and find efficient delivery routes.

### 3. Objectives
- Sort parcels based on deadlines and priorities.
- Maximize parcel priority within a fixed capacity.
- Find shortest paths between delivery locations.
- Generate an approximate delivery route.
- Analyze algorithm execution time.

### 4. Algorithms Implemented

**Sorting Algorithm:** Arranges parcels according to deadline and priority.

**0/1 Knapsack Algorithm:** Uses Dynamic Programming to select parcels with maximum total priority within the given capacity.

**Dijkstra's Algorithm:** Finds shortest distances from the warehouse to other locations.

**Nearest Neighbor Algorithm:** Generates an approximate route by visiting the nearest unvisited location.

### 5. Technologies Used
- Python
- VS Code
- Matplotlib
- NumPy

### 6. Performance Analysis
The project was tested with 10, 50, 100, 500, and 1000 parcels. Execution time was recorded for sorting and Knapsack algorithms. A runtime chart was generated using Matplotlib.

### 7. Results
The program successfully performed parcel sorting, optimized parcel selection, shortest-distance calculation, route planning, and performance testing.

### 8. Conclusion
This project demonstrates the practical application of DAA concepts in courier management. It uses sorting, dynamic programming, graph algorithms, and performance analysis to improve delivery planning.
